Generated with the built-in image generation tool using the user's tropical fishing-game reference as design guidance. Only the above-water environment changes; the approved underwater reef remains intact.

- `sky-backdrop-wide.png`: panoramic desktop backdrop.
- `sky-backdrop-narrow.png`: sidebar backdrop.

The scene loads the appropriate composition and anchors its lower edge to the existing waterline. In tall views, only cloud-free horizontal strips of the narrow artwork expand: 0–12%, 25–30%, and 40–42% of its height. Clouds, cloud banks, islands, and palms retain their proportions. In the VS Code sidebar, the bottom 16% (open sea below the islands) is 35% taller to give the boat a deeper surface-water backdrop. Shorter views clip excess sky above the canvas.
