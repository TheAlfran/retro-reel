# Retro Reel

A compact arcade fishing game made with Phaser 3, TypeScript, and Vite.

## Run it

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Install it in VS Code

Build the browser game and package the extension:

```bash
npm run package:vsix
```

Then open VS Code’s Extensions view, choose **Install from VSIX…**, and select `retro-reel.vsix`. Select the boat icon in the Activity Bar to play in the **Retro Reel** sidebar. You can also run **Retro Reel: Go Fishing** from the Command Palette to play in a larger editor tab.

## Controls

- **Left / Right** or **A / D** — sail while the hook is aboard
- **Space** — cast, reel, start, and restart

Deeper fish are worth more points. Golden tuna are quick and valuable. Keep an eye on line tension: a snapped line costs three seconds.
